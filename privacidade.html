Política de Privacidade

Atualizada em 18 de novembro de 2026

Quem usa

O Joker é um assistente pessoal de uso privado. O único usuário é o próprio dono, que autoriza o acesso às próprias contas. Ele não é vendido nem oferecido a outras pessoas.

Quais dados ele acessa

  • Gmail (somente leitura): remetente, assunto e um trecho dos e-mails, para apontar o que é importante e filtrar propaganda.
  • Google Agenda (somente leitura): compromissos, para lembrar o dono do dia.
  • Google Ads (somente leitura): gasto e resultado das campanhas do próprio dono.

Como os dados são usados

Os dados são usados apenas para mostrar resumos e avisos ao próprio dono, no computador dele. O Joker não envia e-mails, não apaga mensagens e não altera campanhas.

Armazenamento

As autorizações ficam guardadas só no computador do dono. Os dados não são vendidos, não são compartilhados com terceiros e não são usados para publicidade nem para treinar modelos de IA.

Uso de dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
